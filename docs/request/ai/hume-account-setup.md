# Hume 계정 — AI가 소유합니다. 결제도 그 계정 위에서 합니다

> **상태: ⏳ 회신 대기** (요청 2026-09-04)
> 회신은 `../../response/backend/hume-account-setup.md`에 들어옵니다.
> **막고 있는 작업**: **백엔드 Phase 2의 `POST /api/session/start` 실동작**(Hume 단기 토큰 발급 · `humeConfigId`)과 **9/6 통합 테스트 전체.** Free 티어로는 통합 테스트조차 성립하지 않습니다(월 5분·동시 접속 1, 하드 컷이 7분).

- 요청자: 백엔드 (팀장 · 예산 주체)
- 대상: AI
- 관련 문서: `../../00-context/prd.md` §11·§14-3 · `../../response/backend/integration-test-path.md` "함께 알려드리는 것"

---

## 결정 — 계정은 AI가 만들고 소유합니다

알려주신 문제(`config_id`가 워크스페이스에 묶여서 Config 계정과 결제 계정이 갈리면 쿼터가 적용되지 않는 것)에 대한 팀 결정입니다.

**AI 쪽에서 계정을 만들어 소유해 주세요.**

- **테스트를 전부 AI 쪽에서 진행합니다.** 계정을 다른 사람이 들고 있으면 Config 설정·수정마다 왕복이 생깁니다
- **대시보드를 봐야 하는 쪽도 AI입니다** — 사용량·세션 로그·에러를 실시간으로 봐야 하는 건 EVI를 직접 붙이는 쪽입니다
- 백엔드는 그 계정에서 발급된 **API 키와 `config_id`만** 받아 환경변수에 넣습니다

**결제도 그 계정 위에서 합니다.** 그게 이 문제의 요건 전부입니다 — 카드 주체와 정산은 팀 내부에서 처리하고, 기술적으로 지켜야 하는 건 **"결제가 Config를 만든 계정에서 이뤄질 것"** 하나입니다.

## 예산 — 크리에이터 플랜까지 승인합니다

**상한을 Creator 플랜까지로 둡니다.** 그 아래에서 충분하면 낮은 플랜으로 가세요 — 상한이지 지정이 아닙니다.

판단에 필요한 사실을 정리하면 —

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 필요 분량 | **약 490분** (개발 테스트 300 + 도그푸딩 90 + 리허설·본선 100) | PRD §11 |
| 필요 동시 접속 | **3** (3인 도그푸딩) | PRD §11 |
| Starter 동시 접속 | **5** | 알려주신 값 (2026-09-04) |

**동시 접속만 보면 Starter로 충분합니다**(5 ≥ 3). 그래서 상위 플랜의 값어치는 **포함 분수와 초과 단가**에 있습니다 — 490분을 어느 쪽이 싸게 넘기는지가 기준입니다.

## 요청 — 콘솔에서 확인하고 알려주세요

PRD §2.5가 **3자 문서의 요금 정보를 확정값으로 쓰지 않는다**고 못박아서, 결제 전에 콘솔에서 실측이 필요합니다. 계정을 만드시면서 같이 봐 주세요.

1. **플랜별 포함 분수와 초과 단가** — Starter / Creator 각각. 490분 기준으로 총액을 비교할 수 있게
2. **플랜별 동시 접속 수** — Starter 5는 알려주셨고, Creator 값
3. **신규 계정 $20 크레딧이 EVI 사용료에 적용되는지** — 적용되면 490분이 사실상 덮여 PRD §11의 약 $37 추산이 크게 달라집니다
4. **결제 수단을 등록할 위치** — 그 계정의 Billing에 등록하면 되는지, 팀/워크스페이스 단위 결제가 별도로 있는지

**총액이 예상을 넘으면 결제 전에 알려주세요.** 승인 상한은 Creator 플랜이지만, 초과 사용료까지 포함한 총액은 함께 보고 정하겠습니다.

## 결정하고 나면 백엔드에 넘겨주실 것

| 항목 | 쓰이는 곳 |
| --- | --- |
| **Hume API 키** | 백엔드 환경변수 `HUME_API_KEY`. **단기 액세스 토큰 발급에만** 씁니다 — 앱에는 절대 내려보내지 않습니다(FR-013·TC-03) |
| **`config_id`** | 백엔드 환경변수 `HUME_CONFIG_ID`. `POST /api/session/start` 응답으로 앱에 전달합니다(계약 §2-4). **없으면 서버가 기동하지 않습니다**(기동 시 fail-fast) |

**둘 다 저장소에 넣지 않습니다.** `X-Internal-Secret`과 같은 경로로 주세요.

## 참고 — 이게 9/6을 막습니다

통합 순서 1번이 `GET /internal/sessions/{id}`라 그 자체는 Hume 없이도 검증됩니다. 다만 **EVI를 실제로 붙이는 순간부터는 유료 플랜이 필요**하고, Free는 하드 컷 7분짜리 세션 **하나가 월 할당량(5분)보다 깁니다.** 계정·결제가 늦어지면 9/6에 붙일 수 있는 것이 내부 API 4종까지로 줄어듭니다.
