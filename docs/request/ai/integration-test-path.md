# 통합 테스트 경로 요청 — 로컬끼리는 서로 도달하지 못합니다

> **상태: ⏳ 회신 대기** (요청 2026-09-04)
> 회신은 `../../response/backend/integration-test-path.md`에 들어옵니다.
> **막고 있는 작업**: AI서버 ↔ 백엔드 내부 API 4종의 **실제 통합 검증**. 양쪽 단위 개발은 막지 않습니다 — 계약(v1.3)이 확정돼 있어 각자 목으로 진행할 수 있습니다.

- 요청자: 백엔드
- 대상: AI
- 관련 문서: `../../02-architecture/api-contract.md` §3(v1.3) · `../../00-context/prd.md` §12(2026-09-04 개정)

## 배경 — 배포를 미루기로 하면서 생긴 문제

팀 결정으로 **배포는 세 파트의 기능 확인이 끝난 뒤에** 합니다(PRD §12, 2026-09-04). 그런데 그 "기능 확인"을 하려면 서비스끼리 도달해야 하는데, **둘 다 로컬이면 도달할 수 없습니다.**

| 호출 | 방향 | 로컬에서의 문제 |
| --- | --- | --- |
| `POST /internal/turns` | AI서버 → 백엔드 | AI서버가 도는 PC에서 `localhost:8080`은 **그 PC 자신**이다. 백엔드는 다른 사람 PC에 있다 |
| `GET /internal/sessions/{id}` | AI서버 → 백엔드 | 같은 문제. **CLM 인증 경로라 이게 막히면 대화 자체가 401**이다 |
| `POST /internal/summaries` | 백엔드 → AI서버 | AI서버는 Hume 때문에 이미 ngrok으로 열리므로 이 방향은 문제없어 보입니다 |
| `POST /internal/observations` | 백엔드 → AI서버 | 위와 동일 |

즉 **AI서버 → 백엔드 방향만 경로가 없습니다.**

## 백엔드가 하려는 것

**통합 테스트 동안만 백엔드도 터널(ngrok 등)로 열겠습니다.** 배포가 아니라 임시 경로이며, 세 파트 확인이 끝나면 정식 배포(Render)로 갈아탑니다.

- 백엔드 로컬 포트는 **8080**입니다 (`server.port: ${PORT:8080}`)
- 터널을 여는 시점은 서로 맞춰야 합니다 — 제 PC가 켜져 있을 때만 유효하고, 무료 ngrok은 재시작 시 URL이 바뀝니다

## 결정을 요청하는 것

1. **이 방식에 동의하는지.** AI서버가 백엔드를 부르는 구간만 터널로 열면 되는데, 혹시 **양쪽을 한 PC에서 같이 띄우는 편이 나은 상황**이면(예: AI 쪽에서 백엔드 컨테이너를 같이 돌리는 게 편하다면) 그쪽으로 맞추겠습니다.
2. **통합 시점.** 백엔드 Phase 2·3(`/internal/turns`·`GET /internal/sessions`)이 서면 바로 붙여보고 싶습니다. AI 쪽 준비 시점을 알려주시면 그때 터널을 엽니다.
3. **붙이는 순서.** `GET /internal/sessions/{id}`부터 하는 것을 제안합니다 — **CLM 인증 경로라 이게 안 되면 나머지가 전부 401로 막혀서**, 다른 걸 먼저 붙여도 검증이 안 됩니다.

## 함께 알려드리는 것 (요청 아님)

- **`.env.example`의 `BACKEND_BASE_URL`이 `http://localhost:8000`인데 백엔드는 8080입니다.** 해빙 프로젝트 설정을 그대로 가져오면서 `${PORT:8080}`으로 확정됐습니다. 계약서에 로컬 포트 규정이 없어 어느 쪽도 틀린 건 아니었고, 이제 8080으로 맞춰주시면 됩니다.
- **`AI_TURN_POST_RETRIES`가 아직 `1`입니다.** v1.3에서 **3회**로 올렸습니다(계약 §3-2, `response/ai/session-context-lookup.md` 5번). 데모 계정 전용 분기 없이 전 세션 동일 적용입니다.
- **`X-Internal-Secret` 값**은 통합 시작할 때 별도 경로로 전달하겠습니다. 저장소에 넣지 않습니다.
- **PRD §12가 개정됐습니다** — 9/10이 일정 상수에서 **팀 내부 목표**로 바뀌었습니다. 고정 마감은 9/20 제출 하나입니다. AI 요청서에 "9/10 도그푸딩은 고정 임계값으로도 성립합니다"라고 적어두신 부분의 전제가 달라졌으니 참고 부탁드립니다.
