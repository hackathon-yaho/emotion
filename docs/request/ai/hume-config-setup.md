# Config에 CLM이 안 붙어 있습니다 — 지금 상태로는 우리 AI서버가 한 번도 안 불립니다

> **상태: ⏳ 회신 대기** (요청 2026-09-05)
> 회신은 `../../response/backend/hume-config-setup.md`에 들어옵니다.
> **막고 있는 작업**: **TC-02(실제 3분 대화)와 통합 3번 전체.** 백엔드 쪽 토큰 발급은 실물로 확인됐고, 남은 것이 Config입니다. **1번(CLM)이 없으면 제품이 성립하지 않습니다.**

- 요청자: 백엔드
- 대상: AI
- 관련 문서: `../../02-architecture/api-contract.md` §4 · `../../02-architecture/ai-pipeline.md` · `../../00-context/prd.md` §14-3 · `../../response/backend/hume-account-setup.md`

## 먼저 — 키를 받아 실물로 붙여봤습니다. **EVI 분수는 0초 썼습니다**

팀장님을 통해 `HUME_API_KEY`·`HUME_SECRET_KEY`를 받았습니다. **소켓은 한 번도 열지 않았습니다** — 토큰 발급·Config 조회·채팅 목록은 전부 REST라 분수를 깎지 않습니다. **계정 설정은 아무것도 바꾸지 않았고 읽기만 했습니다.**

| 확인 | 결과 |
| --- | --- |
| `POST /oauth2-cc/token` | ✅ **200**, `expires_in: 1799` |
| `POST /api/session/start` (백엔드) | ✅ **201 + 실물 `humeAccessToken`** |
| `GET /v0/evi/configs` | ✅ 200 — Config 1개 |
| `GET /v0/evi/chats?status=ACTIVE` | ✅ 200 — 활성 0건 |

**`HUME_CONFIG_ID`는 `23d6162d-d334-44dd-9c2d-f5858de19a06`입니다** (9/5 03:24 생성). 저희 `.env`에 넣었습니다. **다른 Config를 쓰실 거면 알려주세요.**

> **백엔드에서 결함 1건이 나와 고쳤습니다** — Hume의 토큰 엔드포인트가 **200에 `Content-Type` 헤더를 안 싣습니다.** 응답을 `Map`으로 받으면 Spring이 변환기를 못 골라 **키가 틀린 것과 똑같은 503**이 납니다. `String` 파싱으로 바꾸고 회귀 테스트로 묶었습니다. **그쪽에서 Hume REST를 부르실 일이 있으면 같은 함정이 있습니다.**

## ⛔ 1. `language_model`이 `null`입니다 — 가장 급합니다

```json
"language_model": null,
"ellm_model": { "allow_short_responses": false }
```

**이 상태면 Hume이 자기 내장 LLM으로 대답합니다.** 계약 §4의 `POST /chat/completions`가 **한 번도 호출되지 않습니다.**

그러면 이런 게 전부 안 돕니다 — **갭 산출 · 되묻기 · 위기 감지(F4) · 턴 적재 · 관찰 · 요약.** 사용자에게는 "그냥 잘 대답하는 음성 봇"으로 보이고, **이 제품의 주장이 통째로 빠집니다.**

`language_model`에 **AI서버의 CLM 엔드포인트를 등록해 주십시오.**

## ⚠️ 2. 비활성 타임아웃이 **120초**입니다

```json
"timeouts": {
  "inactivity":   { "enabled": true, "duration_secs": 120 },
  "max_duration": { "enabled": true, "duration_secs": 1800 }
}
```

**감정 대화에서 2분 침묵은 흔합니다.** 울거나, 생각하거나, 말을 고르는 시간입니다. 지금 설정이면 **그때 Hume이 소켓을 끊습니다.**

- **우리 하드컷은 7분인데 비활성 2분이 먼저 걸립니다** — 설계상 하드컷이 상한이어야 하는데 실제 상한이 다른 값이 됩니다
- 끊긴 뒤 앱이 재연결하면 **새 채팅**이라 맥락이 끊깁니다
- 최대가 1,800초라 **하드컷 420초를 넉넉히 덮을 수 있습니다**

**얼마로 하실지는 AI 판단에 맡깁니다.** 다만 **420초보다는 커야** 하드컷이 실제 상한이 됩니다.

> `event_messages.on_inactivity_timeout`이 `enabled: false`입니다. 끊길 때 사용자에게 아무 말도 없이 끊긴다는 뜻으로 읽힙니다 — 함께 보시면 좋겠습니다.

## ⚠️ 3. 음성이 영어입니다

```json
"voice": { "name": "Kora", "tags": { "LANGUAGE": ["English"], "ACCENT": ["American","California"] } }
```

**한국어 제품입니다.** PRD §1이 근거로 삼은 "Hume이 한국어를 공식 지원한다"가 여기서 실물이 돼야 합니다.

## ⚠️ 4. `nudges`가 3초입니다

```json
"nudges": { "enabled": true, "interval_secs": 3 }
```

**3초마다 사용자를 재촉합니다.** 침묵을 견디는 것이 이 제품의 태도인데(FR-030 되묻기도 "몰아붙이지 않는다"가 전제입니다), **우는 사람에게 3초마다 말을 거는 셈**입니다. 끄거나 크게 늘리는 쪽을 권합니다.

## 5. `evi_version`이 `"3"`입니다 — CLM 지원 방식 확인 부탁드립니다

Config가 EVI 3으로 만들어져 있습니다. **계약 §4와 `ai-pipeline.md`가 전제한 CLM 인터페이스가 EVI 3에서 같은 모양인지** 확인 부탁드립니다. 다르면 계약 §4를 먼저 고쳐야 합니다.

## 6. 플랜 — 지금 무료면 **동시 접속 1**입니다

요금 페이지를 다시 읽었습니다.

| 플랜 | 월 | 포함 분수 | **동시 접속** |
| --- | ---: | ---: | ---: |
| Free | $0 | 5분 | **1** |
| Starter | $3 | 40분 | 5 |
| **Creator** | **$7** | **200분** | **5** |
| Pro | $70 | 1,200분 | 10 |

**Creator로 올려도 동시 접속은 안 늘어납니다**(Starter와 같은 5). Creator의 값어치는 **포함 분수 40 → 200분**에 있습니다 — 회신하신 계산 그대로입니다.

**지금 무료면 두 번째 사람이 이미 거절당합니다.** 3인 도그푸딩이 성립하지 않습니다. **결제 시점을 알려주시면** 저희가 대기열 기본값을 그에 맞춥니다(아래).

## 부탁드리는 것 하나 더 — `chats?status=ACTIVE`의 한도

**동시 접속이 찼을 때 6번째 사용자에게 대기 순번을 보여주는 기능을 만듭니다**(팀장 결정, 2026-09-05). 정원 판정을 **`GET /v0/evi/chats?status=ACTIVE`로** 하려고 합니다 — Hume이 E0700을 판정하는 그 숫자를 그대로 보는 게 가장 정확해서입니다.

- **줄 맨 앞 1명의 폴링에서만** 부릅니다. **2초에 1회**로 고정됩니다
- **이 엔드포인트의 레이트리밋을 아시면 알려주십시오.** 문서에서 못 찾았습니다
- 조회가 실패하면 **입장을 허용**합니다(fail-open) — 조회가 죽었다고 대화를 막지 않습니다

## 회신 부탁드립니다

1. **CLM 등록 시점** — 이게 통합 3번 전체를 막고 있습니다
2. **비활성 타임아웃을 얼마로 하실지** (420초 초과여야 합니다)
3. 음성·nudges 조정 여부
4. **EVI 3에서 CLM 인터페이스가 계약 §4와 같은지**
5. 유료 전환 시점 (대기열 정원 기본값을 맞춥니다)

## 함께 알려드리는 것 (요청 아님)

- **Config를 고칠 때마다 `HUME_CONFIG_ID`가 바뀌면 알려주세요.** 버전만 오르는 것이면 그대로 두겠습니다
- 저희는 **읽기만 했습니다.** Config·프롬프트·음성 어느 것도 바꾸지 않았습니다
- **`prompt.text`가 `"You are a helpful assistant."`입니다.** CLM을 붙이면 이 프롬프트가 어떻게 되는지(무시되는지, 우리 프롬프트 앞에 붙는지) 확인해 보실 만합니다 — 붙는다면 `ai-pipeline.md`의 프롬프트 설계와 겹칩니다
