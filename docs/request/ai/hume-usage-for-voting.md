## 무엇이 바뀌나

원티드가 **투표자·심사위원이 로그인 없이** 서비스를 써 볼 수 있게 해 달라고 안내했습니다(심사·투표 **9/21~10/5**, 본선이면 10/17까지). 그래서 `POST /api/auth/dev`를 만들었습니다 — 누르면 익명 프로필이 생기고 **바로 음성 대화를 시작할 수 있습니다.**

로그인 경로에는 분당 30회 제한을 걸었지만 **대화 자체에는 상한을 코드로 걸지 않았습니다.** 돈을 내는 계정(Hume 콘솔)에서 거는 게 가장 확실하고, 코드 상한은 그걸 흉내 내는 것이라서입니다. **콘솔에 그런 기능이 없다고 확인되면** 백엔드가 둘러보기 세션에 하루 상한을 넣습니다.

참고 규모 — 세션 하드 컷 7분, 투표자 100명이 3분씩만 써도 **300분**입니다.
