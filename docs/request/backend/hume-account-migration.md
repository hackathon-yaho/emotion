# Hume 계정이 잠겼습니다 — 새 계정으로 옮기면 백엔드 환경변수 3개를 바꿔야 합니다

> **상태: ⏳ 회신 대기**
> **막고 있는 작업**: **아직 없습니다.** 새 계정·새 Config가 만들어진 뒤에 시작됩니다. **미리 알려 드리는 것**이니 지금 손대실 것은 없습니다.
> **⚠️ 다만 그 순간 대화가 통째로 멈춥니다** — 백엔드가 옛 키로 EVI 토큰을 못 받고, `POST /api/session/start`가 503으로 떨어집니다.

- 요청자: AI
- 대상: 백엔드
- 관련 문서: `../../02-architecture/api-contract.md` §2-4 · `backend/docs/phase-2` · `backend/docs/phase-7`

## 무슨 일이 있었나

**공용 구글 계정으로 만든 Hume 계정이 "비정상 행동 감지"로 잠겼습니다** (2026-09-07, 팀장 확인). 계정을 새로 만들어야 하고, **Config는 계정에 딸린 값이라 같이 다시 만들어야 합니다.**

## 바꿔야 하는 것 — 백엔드 환경변수 3개

Render 환경변수입니다. **세 개가 한 세트로 같이 바뀝니다.**

| 변수 | 지금 | 바뀌면 |
| --- | --- | --- |
| `HUME_API_KEY` | 옛 계정 | **새 계정 키** |
| `HUME_SECRET_KEY` | 옛 계정 | **새 계정 시크릿** |
| `HUME_CONFIG_ID` | `23d6162d-d334-44dd-9c2d-f5858de19a06` | **새 Config의 id** |

**셋 중 하나만 옛 값이면 조합이 깨집니다.** 특히 `HUME_CONFIG_ID`는 계약 §2-4에서 **null 불가·기동 시 fail-fast**라, 값이 비면 서버가 아예 안 뜹니다. 옛 값이 남아 있으면 그것보다 나쁩니다 — **뜨긴 뜨는데 앱이 없는 Config로 소켓을 열어 실패합니다.**

## AI 쪽에서 같이 바꾸는 것

| 곳 | 무엇 |
| --- | --- |
| `ai-server/.env` | `HUME_API_KEY`·`HUME_CONFIG_ID` (점검 도구 전용, 대화 경로 아님) |
| `ai-server/app/config.py` | **`hume_config_id` 기본값을 지웠습니다** |

> **기본값을 지운 이유를 남깁니다.** 코드에 옛 Config id가 박혀 있어서, `.env`를 안 채운 사람이 **남의 계정에 있던 죽은 Config를 검사하고 "전부 통과"를 볼 수 있었습니다.** 지금은 비어 있으면 도구가 "채우세요"라고 말합니다. `.env.example`도 같이 비웠습니다.

**앱은 고칠 것이 없습니다.** `humeConfigId`를 `POST /api/session/start` 응답으로 받으므로(계약 §2-4), 백엔드 환경변수만 맞으면 그대로 따라옵니다.

## 새 Config에 넣어야 하는 값 — 전부 다시 설정해야 합니다

**Config는 복사되지 않습니다.** 콘솔에서 새로 만들고 아래를 그대로 넣어야 합니다. 하나라도 빠지면 조용히 다르게 동작합니다.

| 항목 | 값 | 빠뜨리면 |
| --- | --- | --- |
| **EVI 버전** | **`4-mini`** | ⛔ **EVI 3은 영어 전용입니다.** 한국어가 안 됩니다 |
| **언어 모델** | `CUSTOM_LANGUAGE_MODEL` | ⛔ Hume이 자기 모델로 답하고 **우리 서버가 안 불립니다** |
| **CLM 주소** | `https://emotion-ai-server-gq7yhdrrlq-du.a.run.app/chat/completions` | 소켓은 붙는데 대화가 안 됩니다 |
| **음성** | `Jin-Hee` (한국어) | 영어 음성이 한국어를 읽습니다 |
| **비활성 타임아웃** | `420`초 | 하드컷보다 짧으면 침묵으로 대화가 끊깁니다 |
| **최대 길이** | `1800`초 | — |
| **첫 인사말** | `안녕하세요. 오늘 하루는 어떠셨나요?` | 자동 생성이라 매번 달라집니다 |
| **넛지** | 끔 | 감정 대화에서 짧은 넛지는 재촉이 됩니다 |
| **프롬프트** | 비움(`null`) | CLM을 쓰므로 Hume 쪽 프롬프트는 필요 없습니다 |
| **`end_of_turn_silence_ms`** | **`1800`** | 기본 800ms면 **말 고르는 침묵을 턴 종료로 읽어** 한 마디가 여러 턴으로 쪼개집니다 |
| **`min_interruption_ms`** | **`1200`** | 기본 800ms면 **"음…"·"네…" 맞장구에 AI가 말을 멈춥니다** |

마지막 두 개는 **이번에 새로 넣는 값**입니다(2026-09-07 실측 — 2분에 assistant 턴 12번). 옛 Config에는 없었습니다.

## 확인은 이 한 줄로 됩니다

**EVI 분수를 쓰지 않습니다** — REST 조회입니다.

```powershell
cd ai-server
.\.venv\Scripts\python.exe -m app.humeconfig
```

위 11개 중 검사 가능한 항목을 전부 대조하고, 어긋난 것만 「고쳐」로 찍습니다. **「전부 통과했습니다」가 나오면 그때 백엔드 환경변수를 바꾸시면 됩니다.**

## 순서 제안

1. 팀장이 새 계정 + 새 Config 생성
2. **`python -m app.humeconfig`로 Config 검증** (분수 안 씀)
3. 통과하면 → 백엔드 Render 환경변수 3개 교체 → 재기동
4. `POST /api/session/start`가 201에 실물 토큰을 내는지 확인
5. 그다음 대화 1회

**3번 전에 2번을 하는 것이 요점입니다.** Config가 틀린 채로 대화를 걸면 유료 분수를 원인 찾는 데 씁니다.

## 요청자 후속 작업

**새 Config가 생기면 제가 먼저 검증하고 알려 드리겠습니다.** 그 뒤에 환경변수를 바꾸시면 됩니다.
