# 이어하기의 `resumedChatGroupId`를 채울 경로가 없습니다

> **상태: ✅ 회신 완료** (요청 2026-09-04 · 회신 2026-09-05)
> 회신은 [`../../response/backend/chat-group-id.md`](../../response/backend/chat-group-id.md)에 있습니다.
> **결론**: **받습니다 — 소켓이 열린 직후 `chat_metadata`로 옵니다**(EVI 구현하며 프로토콜로 확인). 값이 그때 이미 손에 있으니 **3안(연결 직후 전송)**으로 부탁드립니다 — 강제 종료를 덮는 것이 그것뿐이고, 2안은 안 해도 됩니다. 제안 모양은 `POST /api/session/{id}/chat-group` + 멱등. **덧붙임**: §2-5-1의 `resumedChatGroupId`가 필수 필드인데 값이 없을 때가 정해져 있지 않습니다 — null 허용이나 빈 문자열 중 하나로 적어 주십시오(앱은 지금 빈 문자열을 "없음"으로 방어 중).

- 요청자: 백엔드
- 대상: 앱
- 관련 문서: `../../02-architecture/api-contract.md` §2-5-1 · `../../00-context/spec.md` F2-07 · `backend/docs/phase-2-session.md` 2-6

## 무엇이 비어 있나

계약 §2-5-1이 이어하기 응답에 **`resumedChatGroupId`** 를 요구하고, 앱은 그걸 EVI 핸드셰이크의 `resumed_chat_group_id`로 넘겨 **이전 대화 맥락을 복원**합니다.

백엔드에는 그 값을 담을 컬럼(`voice_session.hume_chat_group_id`)이 있습니다. **그런데 거기에 값을 쓰는 주체가 어느 문서에도 없습니다.**

`chat_group_id`는 **앱이 Hume과 직접 붙어서** 받는 값입니다. 백엔드는 EVI 소켓에 참여하지 않으므로 스스로 알 수 없고, AI서버도 CLM 요청에서 이 값을 받지 않습니다.

**지금 Phase 2 구현은 이 컬럼을 읽어서 그대로 내려줍니다 — 항상 `null`입니다.** 이어하기 자체는 되지만(남은 시간·같은 Config·같은 임계값은 정상) **맥락 복원만 안 됩니다.**

## 여쭙는 것

### 1. 앱이 `chat_group_id`를 받으십니까?

EVI 연결 후 Hume이 이 값을 주는지, 준다면 어느 시점인지(첫 응답 메타 / 소켓 이벤트) 확인 부탁드립니다.

### 2. 받으신다면 백엔드에 넘겨주실 수 있습니까?

**받으신다면 이렇게 하는 걸 권합니다** — 계약에 필드 하나만 추가하면 끝납니다.

```json
POST /api/session/{sessionId}/end
{ "endReason": "user_end", "chatGroupId": "cg_2b7f11" }
```

- **종료 시점에 한 번만** 보내면 됩니다. 이어하기는 종료된 뒤에야 의미가 있으니 그때 저장하면 충분합니다
- **선택 필드로 둡니다.** 안 보내셔도 종료는 정상 처리되고, 그 세션만 맥락 복원이 안 됩니다
- 앱이 강제 종료되면 `end` 호출 자체가 없으므로 **이 경로로는 못 받습니다.** 그런데 **이어하기가 필요한 상황이 정확히 그 상황**입니다 — 그래서 아래 3번을 같이 여쭙니다

### 3. 아니면 세션 시작 직후에 따로 보내시겠습니까?

강제 종료까지 덮으려면 **연결 직후 한 번** 보내주시는 편이 확실합니다. 그 경우 작은 엔드포인트를 하나 새로 만들겠습니다(계약 §2 신설).

**어느 쪽이든 백엔드 작업량은 비슷합니다.** 앱에서 어느 시점에 값이 손에 들어오는지가 결정 근거라 여쭙습니다.

## 함께 알려드리는 것 (요청 아님)

- **F2-07은 P1이고 스코프 컷 3번**입니다(spec §11). 잘려도 F2-06이 데이터를 지키므로 유실은 없습니다. **급한 건이 아닙니다** — EVI를 붙이시다가 값이 보이면 그때 알려주셔도 됩니다
- 백엔드 이어하기는 이미 동작합니다 — **남은 시간이 새 7분이 아니라 잔여분**으로 나가고(TC-22), 임계값은 그 세션의 스냅샷을 그대로 씁니다
