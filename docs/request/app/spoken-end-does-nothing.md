# 종료 의사를 말해도 아무 일도 일어나지 않습니다 — 음성 종료 요청 1건 + 확인 부탁 1건

> **상태: ✅ 회신 완료** (요청 2026-09-16 · 회신 2026-09-16) — [`../../response/backend/spoken-end-does-nothing.md`](../../response/backend/spoken-end-does-nothing.md)
> (원문 요청 2026-09-16 · **2026-09-16 개정**)
> **개정 내용** — ① 을 「지원할까요?」라는 질문으로 올렸는데, **백엔드 쪽에서 「넣어야 한다」로 결론이 났습니다.** 사용자가 끝내자고 말했는데 「말하고 있습니다」 화면이 그대로 남는 것은 말로 하는 서비스에서 앞뒤가 맞지 않습니다. 질문을 요청으로 바꾸고, **구현 위치·타이밍·오탐 정책**을 함께 적었습니다. ② 는 그대로입니다.
> 회신은 [`../../response/backend/spoken-end-does-nothing.md`](../../response/backend/spoken-end-does-nothing.md)에 들어옵니다.
> **막고 있는 작업**: 없습니다. **① 은 결함이 아니라 새 기능 요청이고, ② 는 원인을 확정하지 못했습니다** — 배포 DB로는 여기까지가 끝입니다.

- 요청자: 백엔드
- 대상: 앱
- 관련: spec F2-03·F2-05 · TC-15·16 · 계약 §2-5 · `app/lib/features/conversation/conversation_screen.dart`

---

## 무슨 일이 있었나

배포본에서 대화 중 **AI가 마무리를 유도하는 말을 했고**, 거기에 *"응 오늘은 여기까지만 하자"*라고 답했는데 **화면에 아무 반응이 없었습니다.** 결국 「대화 마치기」를 눌러 끝냈습니다.

여기서 두 가지가 섞여 있어 나눠 적습니다.

---

## ① 음성으로 대화를 끝내는 경로는 아무도 만든 적이 없습니다 — 결함이 아닙니다

저장소 전체를 확인했습니다.

- **앱**: `_end()`를 부르는 곳은 두 곳뿐입니다 — 「대화 마치기」 버튼, 그리고 420초 하드컷 타이머(`conversation_screen.dart:616`)
- **`SessionClock.softWrap` 상수는 정의만 돼 있고 인자로 쓰이는 곳이 0곳**입니다(`session_models.dart:144`)
- **백엔드**: 종료는 앱이 `POST /api/sessions/{id}/end`를 부를 때만 일어납니다. 서버가 스스로 닫는 경로는 F2-06 스케줄러(30분 미종료 정리, `endReason: "timeout"`) 하나뿐입니다
- **spec F2-03**도 "5분 → AI가 말로 마무리 유도 / 7분 → 앱이 자동 종료"이고, **TC-15·16은 AI가 유도한 뒤 사용자가 `[종료]`를 탭**하는 흐름입니다

**그래서 지금 동작이 설계대로입니다.**

### 덧붙임 — 이번에 들은 "마무리 안내"는 우리 플래그가 만든 게 아닙니다

세션 `546562ae`는 `started_at 08:46:31`, 마지막 턴 `08:50:10` — **경과 219초**입니다. `softWrapSec`은 300초(백엔드 `application.yml:77`)라 **모든 턴에서 `softWrap: false`로 나갔습니다.** 즉 마무리 유도 지시가 프롬프트에 들어간 적이 없고, 응답 LLM이 알아서 그렇게 말한 것입니다. 이건 AI서버 프롬프트 쪽 이야기라 여기서는 적어만 둡니다.

### 부탁드립니다 — 음성 종료를 넣어주세요 (2026-09-16 개정)

처음에는 "지원할까요?"로 여쭸는데, 백엔드 쪽 결론은 **넣어야 한다**입니다. 사용자가 *「오늘은 여기까지 하자」*라고 말했는데 「말하고 있습니다」 화면이 그대로 남아 있으면 안 됩니다. 말로 하는 서비스에서 **종료만 손으로 하는 것**도 앞뒤가 맞지 않습니다.

#### 앱 안에서 끝납니다 — 계약·백엔드·AI서버 변경이 없습니다

| 필요한 것 | 지금 상태 |
| --- | --- |
| 발화 원문 | 앱이 이미 `EviUserSpoke(text)`로 받고 있습니다(지금은 안 씁니다) |
| 종료 호출 + 화면 전환 | `_end({String reason})`이 이미 사유를 받고 `Routes.summary`까지 갑니다 — **부를 곳만 있으면 됩니다** |
| `endReason: "soft_wrap"` | 계약 §2-5와 백엔드 검증 패턴에 이미 있고 **요약 생성 대상**입니다. 백엔드 변경 0 |

**AI서버 판정은 권하지 않습니다.** CLM 응답 스트림에 메타를 실을 수 없고(설계상 금지), 앱에 알리려면 `/api/live` 폴링(§2-13)에 필드를 늘려야 해서 계약과 세 파트가 다 움직이는데다 **최대 2초 늦게 도착합니다.** 앱이 전사를 받는 그 순간 판정하는 쪽이 싸고 빠릅니다.

#### 감지하자마자 끊지는 말아 주세요

*"응 여기까지 하자"* → AI가 *"오늘 이야기 잘 들었어요"* → **그다음** 종료 화면이 자연스럽습니다. 감지 즉시 끊으면 AI 말이 중간에 잘립니다. **플래그만 세워두고 `assistant_end`(AI가 답을 마침) 때 `_end(reason: SessionClock.softWrap)`** 을 부르는 형태를 생각했습니다.

#### 오탐 정책은 정밀도 우선입니다 — 애매하면 안 끊습니다

대화를 잘못 끊는 비용이 큽니다. *"이제 그만 좀 했으면 좋겠어"*(직장 얘기)로 세션이 닫히면 최악입니다. **대화 자체를 끝내겠다는 좁은 표현만** 보고(「오늘은 여기까지」·「그만할래」·「대화 끝내자」 류), 걸리지 않으면 **그냥 넘어가면 됩니다** — 사용자에게는 버튼이 그대로 있으니 막다른 길이 아닙니다. 갭·패턴과 같은 쪽이고, 위기 감지와는 반대입니다.

> 규칙 문구 자체는 앱 쪽에서 정해주세요. 백엔드가 목록을 들고 있으면 바꿀 때마다 요청이 오가야 합니다.

## ② 그 발화가 턴으로도 안 들어왔습니다 — 원인 확정 못 했습니다

음성 종료가 없더라도, 그 말에 **AI가 뭐라도 대답은 했어야 합니다.** 그런데 DB에 흔적이 없습니다.

| 확인한 것 | 값 |
| --- | --- |
| 마지막 assistant 턴 | `turn_index 20`, 08:50:10.906 KST |
| 세션 종료 | 08:50:57 KST, `end_reason: user_end` (버튼) |
| **그 사이 47초 동안의 user 턴** | **0건** |
| `ops_error_log` | 이 세션 관련 0건 |

user 턴이 0건이라는 것은 **Hume이 전사를 만들지 않았다**, 즉 그 발화가 Hume까지 가지 않았다는 뜻입니다. CLM 호출도 없었으니 AI가 답할 일도 없었습니다.

**여기서부터는 앱 쪽 상태를 봐야 합니다.** 마이크 보류(`_micHeld`)가 안 풀린 것이 가장 그럴듯하지만, 코드를 읽어본 범위에서는 영구 보류로 남는 경로를 찾지 못했습니다 — `assistant_end` → `_whenQuiet` → `_releaseMic`, 그게 안 와도 `assistant_message`가 건 15초 타이머, 그것도 없으면 `_startHold`의 1분 cap까지, 풀리는 길이 셋입니다. **그래서 원인이라고 적지 않습니다.**

### 부탁드립니다 — 다음 테스트 때 이것만 봐주세요

`SHOW_ERROR_DETAIL`을 켜고 대화를 끝낼 때, **AI의 마지막 말이 끝난 뒤 화면 상태가 「듣고 있습니다」로 돌아오는지**만 확인해 주세요.

- 「듣고 있습니다」로 **안 돌아온다** → 보류가 안 풀린 것이 맞습니다. `_whenQuiet`의 `gen != _generation` 조기 반환(`evi_service.dart:369`)이 유일하게 `done()`을 영영 안 부르는 길이라 거기부터 보시면 될 것 같습니다
- 「듣고 있습니다」로 **돌아왔는데도** 말이 안 들어갔다 → 마이크가 아니라 소켓·Hume 쪽입니다. 그때는 `make logs`로 AI서버에 CLM 요청이 왔는지부터 보겠습니다

> **한 가지 흘려듣지 마실 것** — 위 47초는 *AI 턴이 기록된 시각*부터 잽니다. AI 음성 재생은 그 뒤로도 이어지므로 **실제로 침묵했던 시간은 47초보다 짧습니다.** 체감보다 짧을 수 있다는 뜻입니다.
