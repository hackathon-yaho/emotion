# AI Response

**AI 담당자가 받는 회신 문서** 폴더입니다. **AI가 다른 담당자에게 보낸 요청**(`../../request/app/`·`../../request/backend/`에 있는 것 중 AI가 쓴 것)을 처리한 사람이, **요청한 사람이 확인할 수 있도록** 어떻게 반영했는지 정리해 이곳에 둡니다.

> **`../../request/ai/`에 들어온 요청의 회신은 여기가 아닙니다.** 그건 AI가 **처리하는** 요청이라, 회신은 **요청한 사람의 폴더**에 씁니다.

## 폴더 이름 규칙

`request/`와 동일하게 **폴더 이름은 "이 문서를 읽을 사람"** 입니다.

- `request/ai/` → AI에게 **보내는 요청**
- `response/ai/` → AI가 보낸 요청에 대한 **회신** (AI가 읽는 문서)

예: 백엔드가 AI에게 요청 → 파일은 `request/ai/`에 생성 → AI가 처리 후 회신 → 파일은 `response/backend/`에 생성.

## 작성 규칙

- **요청 파일 하나당 회신 파일 하나.** 파일명은 원본 요청과 맞춥니다.
- 회신 문서에는 최소한 이 세 가지를 적습니다.
  1. **어떤 요청에 대한 회신인지** (원본 요청 파일 경로)
  2. **무엇을 어떻게 반영했는지** — 결정한 값, 바꾼 스키마, 고친 문서
  3. **요청자가 해야 할 후속 작업이 있는지** (없으면 "없음"이라고 적습니다)
- 요청을 **반영하지 않기로 했다면 그것도 회신**합니다. 이유와 대안을 적습니다. 답이 없는 것과 거절은 다릅니다.
