# Response

`../request/`의 요청을 처리한 뒤, **요청한 사람에게 어떻게 반영했는지 알리는 회신 문서** 폴더입니다.

## 왜 있는가

요청 파일만 있으면 **그 요청이 반영됐는지 확인할 방법이 없습니다.** 상대 저장소 커밋을 뒤지거나 직접 물어봐야 했습니다. 회신을 파일로 남기면 요청자가 자기 폴더만 열어보면 됩니다.

## 폴더 이름 = 이 문서를 읽을 사람

| 경로 | 내용 |
| --- | --- |
| `app/` | 앱이 보낸 요청에 대한 회신 |
| `backend/` | 백엔드가 보낸 요청에 대한 회신 |
| `ai/` | AI 담당자가 보낸 요청에 대한 회신 |

`request/`와 같은 규칙입니다 — 폴더 이름이 **받는 사람**입니다.

```
백엔드 → AI에게 요청       →  request/ai/valence-mapping-table.md      (AI가 읽음)
AI가 처리 후 백엔드에 회신  →  response/backend/valence-mapping-table.md (백엔드가 읽음)
```

작성 규칙은 각 하위 폴더의 README를 보세요.
