## 다만 — **지금 배포본은 서버를 부르지 않습니다**

`SAMPLE_DATA=true`를 저장소 변수로 **일부러 켜 두었습니다.**

**이유는 Hume 과금입니다.** 배포 링크는 팀 밖에서도 열립니다. 지금 상태로 라이브를 켜면 링크를 연 사람이 「오늘 이야기하기」를 누르는 순간 **실제 EVI 통화가 열리고 통화 시간만큼 과금**됩니다. 아직 시연 리허설도 안 한 시점이라, **화면을 먼저 열어 두고 실제 연결은 우리가 켜는 날 켜는** 쪽이 안전하다고 판단했습니다.

그래서 지금 배포본은 —

- 11개 화면이 **준비된 데이터로 전부 그려집니다** — 백엔드 없이도 팀·심사자가 흐름을 볼 수 있습니다
- 카카오 인가 페이지로 가지 않고 그 자리에서 통과합니다
- **`GET /api/health`를 포함해 백엔드 호출이 한 건도 나가지 않습니다.** 그쪽 서버 로그가 조용한 것이 정상입니다

**CORS 설정이 살아 있는지는 이 배포본으로 확인되지 않습니다.** 프리플라이트까지 직접 확인해 주신 것 봤습니다 — 라이브로 켜는 날 저희가 실제 호출로 다시 확인하겠습니다.

## 켜는 방법 — 변수 하나입니다

```sh
gh variable delete SAMPLE_DATA --repo hackathon-yaho/emotion   # 또는 false
gh workflow run app-web.yml --repo hackathon-yaho/emotion
```

**코드는 안 바뀝니다.** `app/README.md`의 「데이터는 어디서 오나」에 같은 내용을 적어 두었고, **제출 전에 반드시 꺼야 하는 항목**으로 「아직 임시인 것」에도 올려 뒀습니다 — 켠 채로 제출하면 심사자가 준비된 데이터를 실제 기록으로 봅니다.

## 앞으로

**라이브 전환은 저희가 먼저 붙여보고 하겠습니다.** 순서는 이렇게 봅니다.

1. 로컬에서 `--dart-define=API_BASE_URL=https://emotion-6yeh.onrender.com`으로 실제 왕복 확인 — 로그인·세션 시작·EVI 소켓
2. 되면 `SAMPLE_DATA`를 끄고 재빌드
3. 그때 CORS·마이크 왕복(PRD §14-4 미검증 항목)을 함께 확인

**커스텀 도메인이 정해지면 알려드리겠습니다.** 재배포 없이 `CORS_ALLOWED_ORIGINS`만 고치면 된다는 것 확인했습니다.

`workflow_dispatch`가 열려 있으니 **급하실 때는 백엔드가 직접 돌리셔도 됩니다** — 다만 위 변수가 켜져 있는 동안에는 몇 번을 돌려도 샘플 모드입니다.
