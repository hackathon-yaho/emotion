| --- | --- |
| `language_model`이 `null` | **맞습니다. 제가 아직 못 넣었습니다** — 넣을 URL이 없었기 때문입니다 |

| 비활성 타임아웃 120초 | **동의합니다. 늘리겠습니다** |

**분수를 0초 쓰고 확인해 주신 것**, REST와 소켓을 구분해서 접근하신 판단이 정확합니다. 무료 5분이 통째로 남아 있는 게 지금 상황에서 큽니다.

## 1. CLM URL — 배포 주소가 나와야 넣을 수 있습니다

**등록 자체가 막혀 있던 게 아니라, 넣을 주소가 없었습니다.** Hume은 CLM URL에 두 가지를 요구합니다.

- `https://`로 시작할 것
- `/chat/completions`로 끝날 것
- **공개 인터넷에서 닿을 것**

AI서버가 로컬 `localhost:8100`에만 있어서 세 번째를 못 채웁니다.

**터널 대신 배포로 갑니다.** 지적하신 그대로입니다 — 터널 주소를 넣으면 터널이 끊길 때마다 대화가 죽고, 껐다 켤 때마다 Config를 고쳐야 합니다. **백엔드가 이미 배포됐으니 AI서버도 배포하면 양쪽이 서로 닿습니다.**

Cloud Run으로 올리고, 주소가 나오면 그 자리에서 `language_model`에 등록하겠습니다.

```
https://<서비스명>-<번호>.asia-northeast3.run.app/chat/completions
```

## 2. 비활성 타임아웃 120초 → 늘리겠습니다

**지적이 맞습니다.** 감정 대화에서 2분 침묵은 이상한 상황이 아니라 **자주 있는 상황**입니다. 울거나, 생각하거나, 말을 고르는 시간입니다. 거기서 소켓이 끊기면 사용자는 "말을 고르다가 버려진" 경험을 합니다.

**우리 세션 상한과 맞추는 것이 맞다**고 봅니다.

| 항목 | 지금 | 바꿀 값 | 근거 |
| --- | ---: | ---: | --- |
| `inactivity` | 120초 | **420초** | 하드 컷과 같게. 침묵으로 세션이 끊기는 경로를 없앤다 |
| `max_duration` | 1800초 | 그대로 | 하드 컷(420초)이 먼저 걸리므로 상관없다 |

**하드 컷보다 짧은 비활성 타임아웃은 우리 설계와 충돌합니다.** 세션을 언제 끝낼지는 우리가 정하기로 돼 있는데(F2-03·FR-011), 지금은 Hume이 먼저 끊습니다.

다만 **분당 과금이라 침묵도 과금됩니다.** 420초는 원가 상한($0.49)을 넘기지 않는 선입니다 — 하드 컷이 어차피 그 시간에 걸리기 때문입니다.

## 참고 — 알려주신 함정 두 개, 잘 받았습니다

**Hume 토큰 엔드포인트가 200에 `Content-Type`을 안 싣는 것** — 저희는 Hume REST를 부르지 않아서(EVI가 우리를 부르는 방향입니다) 당장 해당은 없지만, Config를 프로그램으로 고치게 되면 같은 자리를 밟겠습니다. 기록해 두겠습니다.
