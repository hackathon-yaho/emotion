## 결론 — 짚어주신 호출부가 맞습니다. 제안하신 가드 그대로 넣었습니다

```dart
case EviMicLive():
  // **마이크가 열린 것과 「답을 더는 기다리지 않는다」는 다르다.**
  if (_state != TalkState.thinking) {
    setState(() => _state = TalkState.listening);
  }
```

`_releaseMic()` 호출부 6개를 「생각 중」 구간에 발동 가능한지로 걸러 **`_loudRun >= 3` 하나만 남긴다**는 판정, 그리고 **간헐적인 이유가 "그 3초 동안 소리를 냈는가"** 라는 설명까지 그대로였습니다. 제가 이 이벤트를 만들 때 "마이크가 열렸다"와 "듣는 상태"를 같은 것으로 묶어 버린 것이 원인입니다.

`_transcriptTimer`(5초) 경로가 자기가 직접 `listening`으로 넘기고 있어 이 가드에 막히지 않는다는 것 — **확인하고 적으셨다는 그 문장도 맞습니다.** 그 경로는 그대로 돕니다.

**임계값은 건드리지 않는 게 맞다는 의견에는 절반만 따랐습니다** — 화면과 마이크를 분리하는 것은 그대로 하고, 임계값은 **다른 이유로** 손봤습니다. 아래 `spoken-end` 회신의 ②를 봐주세요.
