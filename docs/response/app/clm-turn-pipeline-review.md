## 제안과 달라진 점 — 응답 스트림에서 메타 태그를 완전히 없앴습니다

요청 문서는 텍스트 valence만 분리하고, 태그·위기 판정은 응답 호출 첫 줄 `<m>{…}</m>`로 두자고 했습니다. **태그·위기 판정도 분석 호출로 옮겼습니다.** 응답 호출의 출력은 이제 대화 텍스트뿐입니다.

| 이유 | 설명 |
| --- | --- |
| TTFT | `<m>` 첫 줄을 파싱하려면 줄바꿈까지 버퍼링해야 하고, 그게 15~20토큰 ≈ 100~200ms입니다. NFR-01의 임계 경로에 그대로 얹힙니다 |
| 위기 톤 전환 | 위기 판정이 응답 **앞에** 확정되므로 응답 프롬프트에 `crisis: true` **플래그**로 들어갑니다. LLM이 응답 도중에 스스로 판단하는 구조보다 결정적입니다 |
| 누출 실패 모드 제거 | 스트림에서 태그를 찾아 제거하는 코드가 **존재하지 않으므로** TTS로 새는 결함이 구조적으로 불가능합니다. CLAUDE.md 경계 감시 항목이 "파싱이 잘 됐는지"에서 "설계상 없어야 하는 게 없는지"로 바뀝니다 |

분석 호출 입력은 **전사 + 직전 4턴의 텍스트 + 세션 기존 태그**입니다. 위기 간접 표현은 맥락 없이는 판정이 안 되지만, 텍스트만 넘기므로 채널 독립성은 그대로입니다. 출력은 `{ text_valence, tags[], crisis, advice_requested }` 구조화 JSON입니다.

최종 흐름(요지 — 전체는 ai-pipeline.md §2):

```
① Hume → 마지막 user 턴 (전사 T, 프로소디 P)
② 세션 컨텍스트 (세션당 1회 백엔드 조회, 캐시)
③ 병렬  voice_valence = 규칙(P)  ·  crisis_rule = 규칙(T)  ·  analyze(T, 텍스트 이력) → text_valence·tags·crisis_llm
④ 규칙  gap · gapTriggered · crisis = rule OR llm · 태그 원문 대조
⑤ respond(텍스트 이력 + 플래그만)  → 대화 텍스트 스트리밍, 메타 태그 없음
⑥ SSE → Hume (버퍼링 없음)
⑦ /internal/turns 비동기 적재 (user 턴은 ④ 직후, assistant 턴은 스트림 종료 후)
```

## 왜 (a) 경량 LLM 호출인가

- 가장 빨리 붙습니다. 이번 주 안에 E2E가 서야 9/10 도그푸딩에 갭 계산까지 들어갑니다.
- **전사 해시 캐시**로 동일 전사에 대한 결정성을 얻습니다. 데모 1번 장면(같은 문장 두 번)에서 텍스트 valence가 두 번 **정확히 같은 값**임이 캐시로 보장됩니다.
- (b) 로컬 모델은 valence만 내므로 태그·위기 판정은 어차피 LLM이 필요합니다. 두 호출로 갈라지는 순간 지연 이득이 사라집니다. `TextAnalyzer` 프로토콜만 두어 나중에 교체 가능하게 했습니다.

2. **폴백 전환 기준** — "연결 실패 2회 또는 첫 응답 5초 초과 시 영상으로"는 PRD §13에 넣지 않았습니다. 그건 발표 대본(§14-7 슬라이드 구성) 결정 시 팀이 함께 정하는 게 맞아 보여서, 그때 이 문장을 그대로 제안하겠습니다.

## 함께 알려드리는 것 (요청 범위 밖)

- **AI서버가 세션 임계값·모드를 알 경로가 계약에 없었습니다.** `/internal/turns`에 `thresholdMode`를 실어야 하는데 Hume은 `custom_session_id`만 줍니다. `request/backend/session-context-lookup.md`로 내부 조회 엔드포인트를 요청했습니다. 이 조회를 **CLM 인증**으로도 씁니다 — `language_model_api_key`는 앱이 `session_settings`로 보내야 해서 웹 번들에 노출되기 때문입니다. 앱은 `session_settings`에 `language_model_api_key`를 **넣지 않으셔도 됩니다.**
- **세션 요약(F2-05) 생성 경로도 계약에 없었습니다.** `request/backend/session-summary-endpoint.md`로 요청했습니다.
- **`hume-config-id.md` 5번(Config 소유)** — Hume 콘솔 Config는 **AI 담당이 생성·소유**하겠습니다. CLM URL·언어 설정이 제 작업이고, 콘솔 프롬프트는 비워둡니다(우리 서버가 시스템 프롬프트를 씀). 백엔드 회신에서 이대로 확정되면 `config_id`를 백엔드 환경변수로 전달합니다.
- **`live-turn-signal.md` 6번(데모 세션 적재 재시도)** — AI서버 쪽은 재시도 횟수를 환경변수로 두어 언제든 올릴 수 있습니다. 데모 계정만 특별 처리하지 않고 전체를 올리는 쪽이 단순합니다. 백엔드 회신에 따릅니다.
- **spec F6-01의 동의어 병합 예시(`미팅`→`회의`)가 FR-043·§1.4 "원문 외 태그 0건"과 충돌**해서 v1은 활용형 정규화만 하고 동의어 병합은 하지 않는 것으로 spec을 고쳤습니다. 앱의 태그 표시에는 영향 없습니다.
