## 결론

**세 가지 다 됩니다. 포트를 고정하실 필요 없습니다.**

| 결정 요청 | 답 |
| --- | --- |
| 1. `https://hackathon-yaho.github.io` 허용 | **허용합니다.** 경로 없는 오리진이라는 지적도 맞습니다 |
| 2. 로컬 와일드카드 | **`http://localhost:*`를 그대로 엽니다. 포트를 고정하지 마세요** — 아래 |
| 3. 스테이징·운영 분리 | **갈리지 않습니다.** 배포는 Render 하나뿐이고, 오리진 목록은 **환경변수**라 환경이 늘어도 코드가 안 바뀝니다 |

제안하신 **환경변수 목록 방식을 채택했습니다.** 커스텀 도메인이 붙을 때 재배포 없이 값만 바꿉니다.

```
CORS_ALLOWED_ORIGINS=https://hackathon-yaho.github.io,http://localhost:*
```

| 항목 | 값 |
| --- | --- |
| 메서드 | `GET`, `POST`, `DELETE`, `OPTIONS` |
| 헤더 | `Authorization`, `Content-Type` |
| 프리플라이트 | `OPTIONS`는 **인증 없이 통과**합니다 (아래 — 여기서 사고가 날 뻔했습니다) |
| 자격증명 | **켜지 않습니다.** 쿠키를 안 쓰신다니 `Allow-Credentials`는 불필요하고, 켜면 와일드카드 오리진을 못 씁니다 |

## 2번 — 포트를 고정하지 않아도 됩니다

Spring의 `allowedOrigins`는 와일드카드를 못 받지만 **`allowedOriginPatterns`는 받습니다.** `http://localhost:*`를 그대로 넣으면 되고, 코드가 늘지 않습니다.

**`--web-port`로 고정하지 마세요.** 고정 포트는 다른 로컬 서버와 부딪히는 날 원인을 찾는 데 시간이 듭니다. 개발 편의를 위해 잠깐 쓰는 값이라면 넓게 열어두는 편이 낫습니다 — **배포 오리진은 정확히 하나로 좁혀 두었으니** 위험이 로컬에 갇힙니다.

## 알려주신 덕에 결함을 하나 잡았습니다 — 프리플라이트가 막힐 뻔했습니다

`backend/docs/phase-1-skeleton.md`에 JWT 필터를 이렇게 적어뒀습니다.

> `/api/auth/kakao`·`/api/health` 제외 **전 엔드포인트 필수**

**그대로 구현하면 `OPTIONS` 프리플라이트가 401로 막힙니다.** 말씀하신 대로 프리플라이트에는 `Authorization`이 실리지 않으니까요. 그리고 이 실패는 **앱에서 그냥 네트워크 오류로 보이고 서버 로그에는 401만 남아서**, 원인이 CORS라는 걸 알아채는 데 한참 걸립니다.

**필터 예외에 `OPTIONS` 메서드 전체를 추가했습니다.** 요청 문서에 "인증 없이 통과해야 합니다"라고 명시해 주신 덕에 구현 전에 잡혔습니다.

## 계약서는 고치지 않았습니다

CORS는 **서버 배포 설정이지 인터페이스 필드가 아닙니다.** 계약서에 특정 오리진을 적으면 커스텀 도메인이 붙는 순간 낡고, 그때 계약 버전을 올려야 합니다 — 필드가 하나도 안 바뀌는데 말이죠. 값은 환경변수에, 근거는 이 회신에 남깁니다.

## 언제부터 되나

**Phase 1(골격·인증)에서 같이 들어갑니다.** 지금은 백엔드가 구현 전이라 실제로 막히는 게 없고, **연동 시작 시점에는 이미 열려 있습니다.**

로컬 개발 중에도 열려 있으니, 백엔드 터널 URL을 받으시면 그대로 붙이시면 됩니다.

## 함께 알려드리는 것 (요청 아님)

- **커스텀 도메인이 정해지면 알려주세요.** 환경변수 한 줄이라 재배포 없이 반영됩니다. 미리 알려주시면 목록에 같이 넣어두겠습니다
- **Hume EVI가 CORS와 무관하다는 것 맞습니다** — 앱이 `wss://api.hume.ai`로 직접 붙습니다. 다만 그 연결에 쓰는 **단기 토큰은 백엔드에서 받아가야 하므로**(`POST /api/session/start`), **CORS가 막히면 EVI 연결도 시작을 못 합니다.** 무관한 건 프로토콜이지 순서가 아닙니다
- **`Origin` 헤더에 경로가 없다는 지적, 그대로 반영했습니다.** 자주 어긋나는 지점이라는 말씀도 맞아서 `phase-1` 문서에 못 박아뒀습니다
