## AI 활용 방식 및 결과 (485자)

말투에서 감정을 읽는 일은 Hume EVI가 목소리의 프로소디를 실시간으로 재고, 대화의 두뇌는 우리 AI서버(Gemini 기반 Custom Language Model)가 맡습니다. 핵심은 역할을 나눈 것입니다. 판정은 코드가 하고 LLM은 문장만 씁니다. 갭(=|말한 내용 − 목소리|)을 코드가 계산해 임계를 넘을 때만 되묻고, 패턴은 3회 이상·평균 1.5배 이상일 때만 관찰로 내보냅니다. 조건에 못 미치면 침묵합니다. 모든 관찰에 근거(횟수·배수·해당 대화)를 붙여 문장과 숫자가 어긋나지 않게 했습니다. 위기 표현은 규칙과 LLM을 OR로 묶어 LLM이 죽어도 규칙만으로 109 안내가 나갑니다. 프로소디 수치는 분석·응답 프롬프트에 넣지 않고 플래그만 보내며, 음성 원본은 서버가 받지도 저장하지도 않습니다. 개발은 3인이 각자 Claude Code로 진행하며 계약서 한 장과 요청·회신 문서로 인터페이스를 맞췄고, 테스트 548건으로 회귀를 잠갔습니다.

> 글자 수는 **공백 포함 485자**입니다(공백 제외 385자). 줄이려면 마지막 문장(개발 과정)을 먼저 덜어내면 됩니다.
