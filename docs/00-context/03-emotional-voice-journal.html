2. 배경 — 왜 지금 이 문제인가

감정 인식 AI 시장은 2024년 29억 달러에서 2034년 194억 달러로 성장할 것으로 전망되며, 음성 AI는 단순 질의응답을 넘어 사용자의 감정을 이해하고 선제적으로 반응하는 방향으로 고도화되고 있다. Hume AI의 EVI 모델처럼 대화 중 목소리 톤을 조절하며 공감하는 음성 AI가 이미 상용화 단계에 접어들었다.

동시에 코로나19 이후 우울·무기력을 호소하는 사람이 늘었지만 전문 심리상담 공급은 수요를 따라가지 못하고 있고, ChatGPT 등 범용 LLM에게 감정을 털어놓는 것이 하나의 일상적 행동으로 자리잡았다. 다만 대부분은 "텍스트로 입력"하는 방식이라 이동 중이거나 지쳐 있을 때는 진입장벽이 있고, 저널링 연구에서도 "경험을 텍스트로 옮기는 과정에서 생각의 속도·감정의 무게·목소리가 낮아지는 순간 같은 비언어적 정보가 유실된다"는 지적이 있다.

4. 정량적 임팩트

29억 → 194억 달러전 세계 감정 인식 AI 시장 규모, 2024년 대비 2034년 전망 (약 6.7배 성장)
170만 명+AI 음성 노트/저널 앱 '플라우드'의 전 세계 사용자 수 — 음성 기반 기록 서비스 수요가 이미 검증된 규모

5. 어떻게 동작하는가

  1. 사용자가 앱에서 마이크 버튼을 누르고 하루 이야기를 말로 함 (전화 통화하듯)
  2. 백엔드가 음성을 STT로 텍스트화함과 동시에, 음성 신호(피치, 속도, 떨림, 쉼)를 별도로 분석해 감정 상태(기쁨/불안/피로/분노 등)를 스코어링
  3. AI(LLM)가 텍스트 내용 + 음성 감정 스코어를 종합해 공감형 응답을 생성 (예: "오늘 목소리에 힘이 없으셨네요, 무슨 일이 있었나요?")
  4. 대화 내용은 자동으로 일기 형태로 정리되어 저장됨
  5. 주간/월간 단위로 감정 점수 변화를 그래프로 시각화, 패턴(예: "매주 월요일 저녁 스트레스 지수가 높아짐")을 알려줌

팀 구성 매칭: 프론트엔드는 음성 녹음 UI와 감정 트렌드 대시보드, AI 담당은 음성 감정 스코어링 모델 통합과 공감 응답 프롬프트 설계, 백엔드는 음성 파일 처리 파이프라인과 시계열 감정 데이터 저장을 담당하면 자연스럽게 역할이 나뉜다.

6. Before / After 시나리오

Before: 재택근무 중인 직장인 A씨는 요즘 이유 모를 무기력함을 느낀다. 일기 앱을 여러 번 깔아봤지만 "오늘 하루 어땠는지" 텍스트로 정리하려니 귀찮아서 사흘을 못 넘기고 지운다.

After: A씨는 퇴근길에 앱을 켜고 3분간 오늘 있었던 일을 그냥 말한다. AI는 A씨의 말투에서 목소리 톤이 낮고 말이 느려진 것을 감지해 "오늘 유독 지쳐 보이시네요"라고 먼저 물어봐준다. 한 달 뒤 A씨는 감정 트렌드 그래프에서 매주 수요일마다 스트레스 지수가 치솟는 패턴을 발견하고, 수요일 업무 배분을 조정하기로 한다.

7. 기존 대체제 상세 비교

서비스기능한계
들어주는일기 (Google Play)전화하듯 음성으로 말하면 AI가 일기·감정 캘린더·월간 마음 리포트로 정리, 문자 입력도 지원감정 판단이 주로 대화 내용(텍스트화된 말) 기반으로 추정됨, 음성 톤 자체를 감정 신호로 쓴다는 근거는 확인 안 됨. 국내 서비스로 직접 경쟁 관계
마음이 (서울시 공공 AI 상담)채팅 기반으로 언제든 감정·상황을 이야기하고 경청받는 공공 서비스텍스트 채팅 중심, 개인화된 장기 트렌드 시각화 없음, 지자체 서비스라 확장 한계

Hume AI (해외)음성 톤 기반 감정 인식 API 자체를 제공하는 인프라 기업소비자 앱이 아닌 개발자용 API — 국내 최종 사용자 저널 앱으로 패키징된 사례는 아님

8. 차별화 포인트

  • 순수 음성 톤 기반 감정 인식: "들어주는일기" 등은 텍스트화된 대화 내용으로 감정을 추정하는 것으로 보이는 반면, 이 서비스는 피치·속도·떨림 등 음성 신호 자체를 1차 감정 신호로 사용해 "말의 내용은 괜찮다고 하는데 목소리는 지쳐 있다" 같은 불일치까지 잡아낼 수 있다
  • 선제적 개입: 기록을 남기고 끝나는 게 아니라, AI가 감정 신호를 먼저 알아채고 되물어주는 상담사형 상호작용
  • 장기 감정 트렌드 대시보드: 요일별/시기별 감정 패턴을 시각화해 데이터 기반 자기 이해를 제공

9. 데모 시나리오 (해커톤 발표용)

1) 발표자가 라이브로 마이크에 대고 지친 톤으로 "오늘 회의가 세 개나 있었는데 다 늘어졌어요..."라고 말한다.
2) 화면에 실시간으로 음성 파형과 함께 감정 스코어(예: 피로도 78%)가 표시되고, AI가 "목소리에 피로가 많이 느껴지네요, 어떤 회의가 제일 힘드셨어요?"라고 되묻는 장면을 보여준다.
3) 미리 준비한 2주치 시뮬레이션 데이터로 감정 트렌드 대시보드를 보여주며 "매주 화요일 피로도가 급증하는 패턴"을 짚어준다.
4) "들어주는일기 같은 기존 서비스는 '뭐라고 말했는지'만 보지만, 우리는 '어떻게 말했는지'까지 본다"는 한 문장으로 차별점을 마무리한다.

10. 리스크 및 대응

리스크: "들어주는일기"라는 유사 국내 서비스가 이미 존재해 "새로운 가치"라는 주장이 약해질 수 있음.
대응: 경쟁 서비스는 텍스트/대화 내용 기반 감정 추정에 머무는 것으로 파악되므로, 음성 신호 자체를 활용한 감정 인식이라는 기술적 차별점을 데모에서 명확히 대비해 보여준다 (같은 문장을 밝은 톤/지친 톤으로 두 번 말해서 결과가 달라지는 것을 시연).
리스크: 음성 감정 인식의 정확도는 사람마다 편차가 크고 검증이 쉽지 않아 "AI가 틀렸다"는 반박이 나올 수 있음.
대응: 감정 스코어를 "확정 진단"이 아닌 "대화를 시작하기 위한 단서"로 포지셔닝, 최종 판단은 항상 사용자와의 대화로 확인.
리스크: 민감한 감정 데이터를 다루므로 개인정보·프라이버시 우려가 클 수 있음.
대응: 데모 단계부터 로컬 저장/암호화 방침 명시, 상담 대체가 아닌 "자기 이해 보조 도구"임을 명확히 고지.
✅ 검증됨: Hume AI EVI API는 개인도 무료로 가입해 바로 쓸 수 있음. 사업자등록 없이 이메일만으로 가입 가능하고, 무료 티어로 월 5분의 EVI(음성 감정 대화) 사용량과 분당 15회 요청이 제공된다. 해커톤 데모(몇 분 분량의 라이브 시연) 용도로는 충분하지만, 실제 여러 사용자가 매일 쓰는 서비스로 확장하려면 유료 플랜 전환이 필요하므로 예산 계획에 반영해야 한다.

11. 4대 심사기준 평가

기준평가근거
기획력중공감대는 명확하나, "들어주는일기"라는 실제 경쟁 서비스가 확인되어 완전히 새로운 아이디어는 아님
실현 가능성상STT + 음성 특징 추출 + LLM 조합으로 해커톤 기간 내 MVP 구현 가능, 상용 음성감정 API 활용 시 더 빠름
확장성중개인 웰빙 시장은 크지만, 상담을 대체하지 못한다는 한계로 B2C 단독으로는 확장 상한이 있음 (기업 EAP 등 B2B 확장 여지는 있음)
AI 활용 적절성상텍스트가 아닌 음성 신호 자체를 감정 인식에 쓰는 것이 AI 없이는 불가능한 핵심 기능
